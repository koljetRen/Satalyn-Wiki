# Satalyn Wiki

A wiki for the world of Satalyn (placeholder name): the setting of *The Runaways* novels and the author's D&D campaigns. Built with [Quartz 5](https://quartz.jzhao.xyz).

- `content/` — the wiki pages (what the website shows)
- `sources/` — the raw notes the wiki is built from (see `sources/README.md`)
- `CLAUDE.md` — writing rules for every Claude session working on the wiki
- `WIKI-PLAN.md` — the build plan and ready-to-paste session prompts
- `templates/` — page templates

Preview locally: `npm ci`, `npx quartz plugin install`, `npx quartz build --serve`, then open http://localhost:8080.
